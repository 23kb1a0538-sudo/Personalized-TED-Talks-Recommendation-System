Problem Statement & Objectives CONTEXT

The Information Discovery Dilemma

TED's repository spans thousands of multidisciplinary talks across technology, psychology, science, and global issues. Users face cognitive overload finding talks aligned with their evolving interests.

  • Pure Content systems suffer from filter bubbles and fail to leverage community taste.
  • Pure Collaborative systems fail on cold-start (unseen talks or new users).
  • Our Solution: A robust, production-grade Hybrid Engine combining text semantics, emotional tone, and latent matrix factorization.

Core Deliverables

  • Cleaned & standardized 2,628 talks + transcripts corpus.
  • 14-dimensional emotional resonance modeling.
  • TF-IDF & 100-factor Latent Semantic embeddings.
  • SVD matrix factorization on 27,430 user interactions.
  • Rigorous offline evaluation (Precision, Recall, NDCG, MAP).
  • Interactive Streamlit web app with explainability.

Feature Extraction & Cleaning Pipeline

Text normalization removes HTML and symbols; combines title (3x weight), tags (3x weight), speaker occupation, description, and transcript lead text into a rich representation. 14 user rating counts are normalized to probability vectors capturing audience emotional impact.

Recommendation Engine Architecture MODULE 3-4

1. Content-Based Layer

  • TF-IDF: 12,000 unigrams + bigrams with sublinear TF scaling.
  • Semantic LSA: 100-component TruncatedSVD capturing thematic topic spaces.
  • Emotional Tone: 14D normalized cosine similarity.
  • Composite Sim: 0.70·TFIDF + 0.20·LSA + 0.10·Emotion

2. Collaborative & Hybrid Layer

  • SVD Factorization: Low-rank decomposition (40 latent factors) on sparse user-item interaction matrix.
  • Dynamic Hybrid Formula:
    S = α·S_content + (1-α)·Norm(S_collab)
  • Cold-Start Router: Graceful automated fallback to content-based similarity for users with <3 interactions.

Hybrid Alpha (α) Optimization TRADE-OFF ANALYSIS

Balancing Discovery & Affinity

Testing alpha from 0.0 (Pure Collab) to 1.0 (Pure Content) on held-out user interactions shows a sweet spot at α = 0.50 to 0.60:

  • Hit Rate@10: Climbs to 11.6% at α=0.40–0.60 vs 7.1% for pure content.
  • NDCG@10: Peaks at 0.0507 with balanced weights.
  • Protects against cold-start while recommending serendipitous talks popular with similar personas.

Why the Hybrid Model Wins

1. Explainability: Content signals allow clear explanations ("Because you enjoyed topics X and Y").

2. Social Proof: Collaborative signals elevate high-quality talks vetted by peer communities.

3. Robustness: Seamless fallback ensures no user ever receives an empty recommendation list.
